# Student Expense Tracker

A React Native + Expo app for tracking student income and expenses.

## Features
- Add income and expense transactions
- Categorize transactions: Food, Travel, Education, Shopping, Bills, Other
- Automatically calculate balance, income, and expenses
- Filter transactions by type
- Delete transactions
- Persist data locally with AsyncStorage
- Display amounts in Indian Rupees (₹)

## Run on your computer
1. Install Node.js.
2. Extract this ZIP file.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npx expo start`
6. Scan the QR code using Expo Go, or use an emulator.

## Open in Expo Snack
1. Visit https://snack.expo.dev/
2. Create a new Snack and replace `App.js` with this project's `App.js`.
3. Add `@react-native-async-storage/async-storage` in the Dependencies panel.
4. Wait for the preview to load.

## Upload to GitHub
Create a public repository named `student-expense-tracker` and upload `App.js`, `app.json`, `package.json`, and `README.md`.

This is a learning project and does not connect to a bank account.
